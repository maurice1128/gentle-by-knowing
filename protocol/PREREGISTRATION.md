## 0. 本文件的地位與修改規則

### 0.1 凍結規則

1. 本文件在**主實驗第一筆資料產生之前**凍結。
2. 凍結後任何修改**一律以 Amendment 附加在 §10**,格式為「日期 / 改什麼 / 為什麼 / 當時已看到哪些資料」。**不得改寫本文正文**(對映 `PAPER_AUDIT_SOP.md` 附錄:歷史紀錄不可改寫)。

### 0.2 什麼算「已經看到資料」

本文件明示區分兩類量測,因為兩者對預先登記的威脅完全不同:

| 類別 | 內容 | 凍結後可否執行 | 條件 |
|---|---|---|---|
| **校準量測(calibration)** | Phase 0 Gate A(接觸拓樸)、Gate B(反射靈敏度)、no-op / random-action 參照、**依變數值域校準**(§6.1) | ✅ **可以,而且必須**在主實驗前跑 | 只允許用來**填入判準的門檻與值域**;結果必須以 Amendment 記錄;**不得改動 H1–H3 的方向、推翻條件、或統計家族定義** |
| **主實驗量測(confirmatory)** | 任何涉及 predictive vs constraint 對比、或 fidelity 掃描的量測 | ❌ 一旦跑過,本文件視為已解凍 | — |

**理由:** 判準的門檻要落在值域內,就必須先知道值域。強行「完全不看資料就定門檻」會製造本文件想避免的那個錯誤本身。所以我們**允許看值域、不允許看對比**,並在 §6 用表格逐條記錄哪個門檻是哪一次校準決定的。

### 0.3 用詞紀律

### H1 — 真模型下,預測式的溫柔優於約束式

**自變數(操弄):** 溫柔控制器類型 `C ∈ {constraint, predictive}`,在他者模型保真度 `f = 1.0`(真模型)且他者模型為 informative 的條件下。

**控制變數:** 兩臂**可得訊號完全相同**(`DIRECTION.md` §5 的兩層分離):自身本體感覺 + 接觸力 + 對方**帶雜訊**運動學。差別只有「predictive 額外持有一個他者模型並用它前瞻」。此點屬 `PAPER_AUDIT_SOP.md` A10 缺陷類(「宣稱兩臂只差一件事但沒讀程式碼」),**驗證方式寫在 §5.C1,不接受口頭宣稱**。

**主要依變數:** `L2_dev`(§3.3),單位:無因次(相對個人無接觸基線的預測激活偏差,時間積分)。
**次要依變數:** `L0_peak`(N)、`L0_impulse`(N·s)、`L0_press_ratio`(對 ISO 10218-2 Annex M 部位限值之比,無因次)、`L1_jerk`(m/s³)、`L1_vapp`(m/s)、`task_success`(0/1 每 episode,seed 層級為比例)。

**預期方向:**
- (a) `L2_dev(predictive) − L2_dev(constraint) < 0`,配對種子 paired t 的 **95% CI 完全落在 0 以下**;
- (b) **同時** `task_success(predictive) ≥ task_success(constraint) − δ_task`,`δ_task` 的值**待 Phase 0 決定**(規則見 §6.1-C4),但必須在看主實驗對比之前寫死;
- (c) Pareto 版本:掃 λ(溫柔權重,§2.6)後,predictive 的 (task_success, −L2_dev) frontier **支配** constraint 的 frontier,即 constraint 沒有任何非支配點。

**什麼推翻它(任一成立即 H1 被推翻,並須在論文中明寫):**

| # | 推翻條件 | 這代表什麼 |
|---|---|---|
| H1-F1 | (a) 的 95% CI 含 0 | 沒有偵測到優勢。寫「we did not detect」,**不寫「沒有優勢」**(SOP A5) |
| H1-F2 | (a) 的 95% CI 完全落在 0 以上 | 預測式在真模型下**更不溫柔**。整個方向的前提失效 |
| H1-F3 | (a) 成立但 (b) 不成立 | 「溫柔」是靠不做任務買來的 → 退化解。等同 no-op 方向,**不算優勢** |
| H1-F4 | (a)(b) 成立但 predictive 的優勢向量在 §5.N1 的 **no-op 方向投影**上佔比 > 50% | 優勢主要來自「碰得少」而非「碰得好」。必須改寫宣稱 |
| H1-F5 | (c) 失敗:兩條 frontier 相交,或 constraint 有非支配點 | 只能宣稱「在特定 λ 下贏」,不能宣稱 frontier 支配。這**不推翻 H1 的 (a)(b)**,但推翻 §2.6 的強版本 |

### H2 — 隨保真度下降,預測式優勢單調衰減並在某點被約束式超越(交叉點)

**自變數:** 他者模型保真度 —— `(axis, factor)`,`axis ∈` `degrade.py` 的七軸,`factor ∈ DEFAULT_FACTORS = (0.25, 0.5, 0.71, 1.0, 1.41, 2.0, 4.0)`。

七軸(逐字取自 `scripts/degrade.py` 的 `AXES`):
`muscle_force`(peak isometric muscle force,N)、`passive_stiffness`(MTU passive-force scale,無因次)、`joint_damping`(N·m·s/rad)、`rom`(關節活動度寬度,rad)、`segment_mass`(kg)、`reflex_gain`(無因次)、`reflex_delay`(s)。

**依變數:** `Δ(axis, f) = L2_dev(predictive @ axis,f) − L2_dev(constraint)`。
**注意 constraint 不依賴 f**(它不持有他者模型),因此 constraint 在整個掃描中是一條**水平參照線**。此設計決議與其風險見 §2.3。

**預期方向:**
- (a) `Δ(axis, 1.0) < 0`(即 H1);
- (b) `Δ` 對 `|log₂ f|` **單調不減**(在 `f < 1` 與 `f > 1` **兩側分別**檢定,不合併);
- (c) 至少在一個軸上存在 `f*` 使 `Δ` 穿越 0,且 `f*` 落在掃描域 `[0.25, 4.0]` **內部**(不在端點);
- (d) `f < 1`(低估 → 過度自信)側的失效以 **L2/L0 上升**表現;`f > 1`(高估 → 過度保守)側的失效以 **task_success 下降**表現。此為 `notes/GAP_CLAIM.md` §3 由 Tian 2022 / Zhao 2020 推出的雙向設計要求。

**什麼推翻它:**

| # | 推翻條件 | 這代表什麼 |
|---|---|---|
| H2-F1 | 所有軸上 `Δ(f)` 在整個 `[0.25, 4.0]` 都 < 0(CI 全在 0 以下) | **交叉點不在掃描域內** → 掃描域太窄。**這不算「沒有交叉點」**,必須先擴掃描域(§7.3 的擴域規則,含防止事後擴域的限制)才能下結論 |
| H2-F2 | 所有軸上 `Δ(f)` 在整個域都 > 0 | 預測式從未贏過 → H1 已先倒,H2 無意義 |
| H2-F3 | 有交叉點但**非單調**(例:`f=0.5` 的 `Δ` 大於 `f=0.25` 的 `Δ`) | 單調性部分假。**交叉點仍可報,但必須報「非單調」並給出 `Δ` 全曲線**,不得只報 `f*` |
| H2-F4 | 交叉點只在 `task_success` 軸出現,`L2_dev` 軸不出現 | **Zhao 2020 型結果**(壞模型 → 保守 → 安全指標反而更好)。必須明寫為 "efficiency-only crossover",**不得表述為安全交叉點**。這是本研究最可能的部分失敗模式(見 §9.3) |
| H2-F5 | 交叉點位置對 λ 極度敏感(不同 λ 給出的 `f*` 區間不重疊) | 「交叉點是一個規格」的宣稱失效,只能報 λ-conditional 曲線 |
| H2-F6 | 某軸的 `Δ(f)` 曲線在該軸的**旋鈕失效檢查**(§5.C3)未通過 | 曲線平坦的原因與科學無關(旋鈕沒作用或飽和)。該軸**不得進入主結果**,只能報為技術限制 |

### H3 — 錯的他者模型比沒有他者模型更危險

**自變數:** 他者模型的三個狀態 ——
`informative`(在真身體上訓練)/ `randprior`(隨機初始化的凍結模型,放進**完全相同**的機制)/ `none`(constraint 臂,不持有他者模型)。

**依變數:** 同 H1(主要 `L2_dev`,次要 L0 / L1 / task_success)。

**預期方向:**
- (a) `L2_dev(randprior) − L2_dev(constraint) > 0`,95% CI **完全落在 0 以上** —— 即「無資訊模型比沒有模型更差」;
- (b) `L2_dev(randprior) − L2_dev(informative) > 0`,CI 完全在 0 以上 —— 即劣化不是機制本身造成的;
- (c) (a) 的效果應在 `f → 0.25` 或 `f → 4.0` 的極端劣化條件上**連續地**接上 randprior,即 randprior 可視為 fidelity 軸的極限點。

**先驗來源(不作為預期效果量):** 第一階段在 myoElbow 上 `randprior − blank = +23.8 [+1.7, +45.8]`(`INHERITED.md`)。**不同身體、不同任務、不同依變數**,只提供方向性先驗,**不得用於功效計算,也不得寫成「我們預期 +23.8」**。

**什麼推翻它:**

| # | 推翻條件 | 這代表什麼 |
|---|---|---|
| H3-F1 | (a) 的 CI 含 0 | 「無資訊模型只是沒幫助,不是有害」。這是**與 H3 不同的結論**,必須照實寫,不得含糊為「傾向更差」 |
| H3-F2 | (a) 的 CI 完全在 0 以下 | 無資訊模型**仍優於**沒有模型 → H3 假。此時必須追查是否為 §5.C2 的機制混淆(隨機模型讓 planner 變保守 = 又一個 Zhao 型假象) |
| H3-F3 | (b) 的 CI 含 0 | 好模型與隨機模型不可區分 → **他者模型的資訊內容不重要**,H1 的因果解釋也隨之瓦解。這是對整個方向最嚴重的單一結果 |
| H3-F4 | (c) 不成立(randprior 落在 fidelity 曲線的外插之外很遠) | randprior 不是 fidelity 軸的極限點,而是另一種東西。必須分開報,不得畫在同一條曲線上 |

**H3 的推翻條件在既有材料中不存在**(`DIRECTION.md` §8 只為「預測狀態 vs 預測力」寫了推翻條件),為本文件新增。見 §9.1。

## 2. 設計

### 2.1 場景

| 元件 | 實體 | 檔案 |
|---|---|---|
| 被照護者身體 | MyoSuite **myoArm**(nq=38,63 MTU,MuJoCo,timestep **0.002 s**,已於 2026-09-05 一手確認) | `scripts/arm_scene.py::build` |
| 反射 / 防禦反應(僅存在於模擬器,機器人看不到) | `StretchReflex`(速度 + 長度回饋 + 傳入延遲 + 一階激活遲滯),結構follow SpasticMyoElbow (Yu et al., arXiv:2412.04700) | `scripts/reflex.py` |
| 機器人 | **Phase 0:** 單自由度 slide probe;**主實驗:** MuJoCo Menagerie 機械臂 | `scripts/arm_scene.py`;主實驗場景**尚未建置** |
| 劣化軸 | 七軸 × 七 factor,雙向 | `scripts/degrade.py` |

**⚠️ 預先登記的設計約束:** 主實驗**不得**用 Phase 0 的 1-DoF probe。理由:1-DoF 的動作空間只剩「進 / 退」,CBF safety filter 在這個空間裡退化成閾值煞車,這正是 `DIRECTION.md` §1 與 `notes/GAP_CLAIM.md` §6 明確禁止的 strawman baseline。**主實驗要求機器人動作空間 ≥ 6 DoF**,否則 H1 的結果不可解釋。見 §9.2。

### 2.2 因子與**可實現的** cell —— 2×2×2 不是完全交叉

`DIRECTION.md` §4 寫的是 2×2×2:
`A ∈ {自身模型 only, 自身+他者}` × `B ∈ {他者 informative, 他者 randprior}` × `C ∈ {溫柔用約束, 溫柔用預測}`。

**這個 8-cell 設計在字面上不是完全交叉,必須先解決:**
- `A = 自身模型 only` 時,`B`(他者模型是 informative 還是 random)**沒有定義**;
- `C = 約束`(CBF 只看得到力與距離)時,他者模型**不被使用**,因此 `A` 與 `B` 對結果沒有因果路徑 → 三個 cell 在數值上會完全相同。

**預先登記的解法(在看到任何資料之前選定):採 variant-1,並把 variant-2 列為預先登記的次要分析。**

| variant | 內容 | 地位 |
|---|---|---|
| **variant-1(主分析)** | 誠實承認這是**巢狀 / 不完全設計**,報 5 個實驗臂 + 2 個參照臂(下表) | ✅ **主分析** |
| variant-2(次要) | 讓 constraint 臂也讀他者模型,但**只用來設 CBF 的不確定性裕度**(UA-PCBF 型),使 `B` 在 `C = 約束` 下仍有因果路徑,恢復完全交叉 | 預先登記的次要分析。若執行,`B` 的效果在兩個 `C` 下分別報,**不做 pooled ANOVA** |

**主分析的實驗臂(variant-1):**

| 代號 | 控制器 | 他者模型 | 用途 |
|---|---|---|---|
| `A0` | constraint(CBF / safety filter) | 無 | H1 / H2 / H3 的共同 baseline。**與 `f` 無關** |
| `A1` | predictive | informative,`f = 1.0` | H1 的實驗臂 |
| `A2(axis,f)` | predictive | informative,劣化至 `(axis, f)` | H2 的掃描,42 個條件(見 §2.4) |
| `A3` | predictive | **randprior**(隨機初始化,機制完全相同) | H3 |
| `A4` | predictive | **無他者模型**(planner 只用自身模型) | 分離「有 planner」與「有他者模型」兩件事。**這一臂在既有材料中沒有,是本文件新增的必要對照**,見 §5.C2 |
| `R0` | no-op(完全不動) | — | 平庸最優解參照,§5.N1 |
| `R1` | random-action | — | 同上 |

**`A4` 為什麼是必需的:** 若只有 `A0` 與 `A1`,則 H1 的優勢可能來自「predictive planner 這個機制」而不是「他者模型的資訊」。`A3`(randprior)控制的是「模型有沒有資訊」;`A4` 控制的是「有沒有模型」。兩者缺一,`A1 − A0` 的因果解釋就不唯一。這是第一階段 `randprior` 方法學的直接延伸(`INHERITED.md`)。

### 2.3 constraint 臂不依賴 `f` —— 這是設計決議,不是疏漏

因為 `A0` 不持有他者模型,`Δ(axis, f) = L2_dev(A2(axis,f)) − L2_dev(A0)` 中只有第一項隨 `f` 變化。

- **好處:** 交叉點的定義乾淨(一條曲線穿越一條水平線)。
- **風險(必須在論文中明寫):** 這使 baseline 在整個掃描中享有「不受模型誤差影響」的優勢。這**正是 `DIRECTION.md` §1 的核心命題**(「約束式的安全保證不依賴模型品質」),所以它是被檢驗的命題本身,不是不公平比較。但審稿人會問,§8 有預備回答。
- **配對:** 儘管 `A0` 與 `f` 無關,**每個 `(axis, f)` 條件仍與同一組種子的 `A0` 配對**,不重跑 `A0`。因此 `A0` 的 seed 層級數值在整個掃描中重複使用 —— **這造成 43 個 `Δ` 之間非獨立**,多重比較家族 `F4`(§4.5)明列此事,且 §4.6 的 bootstrap 以 seed 為重抽單位以正確傳遞這個相關結構。

### 2.4 保真度掃描的實際條件數

`degrade.py::sweep_spec` 的行為:七軸 × 七 factor,但 `f = 1.0` **在整個 spec 中只出現一次**(記為 `("truth", 1.0)`)。

因此:**7 × 6 + 1 = 43 個條件**,不是 49。任務描述中的「七軸 × 七 factor」字面上是 49,實際是 43。論文中**必須寫 43**。

`f` 在 log₂ 尺度上對稱:`log₂(0.25, 0.5, 0.71, 1.0, 1.41, 2.0, 4.0) ≈ (−2, −1, −0.5, 0, +0.5, +1, +2)`。單調性檢定在此尺度上進行。

### 2.5 種子數與試驗數

| 項目 | 值 | 理由 |
|---|---|---|
| **配對種子數 `n`** | **30** | 主要統計量是 paired t 的 95% CI(不是 p 值)。n=30 給出的 CI 半寬約 `0.37 × SD_diff`(t₀.₉₇₅,₂₉ = 2.045)。這是**在不知道效果量的情況下**能預先登記的量;實際功效**待 Phase 0** 用 `A0` 臂自身的 seed 散布估出 `SD_diff` 的量級後,以 Amendment 回填(§6.1-C6) |
| **每條件的評估 episode 數 `E`** | **20** | |
| **配對規則** | 種子 `s` 決定:他者模型初始化、模型訓練資料的 babble 隨機流、評估 episode 的初始姿勢與運動學雜訊實現。**所有臂在相同 `s` 下看到完全相同的這三樣東西** | 配對種子的意義 |
| **聚合順序(關鍵)** | **先把 `E=20` 個 episode 聚合成一個 seed 層級純量,再對 `n=30` 個 seed 做 paired t** | 避免 pseudoreplication。若對 600 個 episode 直接做 t 檢定,CI 會假性變窄。**這條在第一階段沒有明文寫,本文件寫死** |
| **seed 層級聚合函數** | `L2_dev`、`L0_impulse`、`L1_*`:**中位數**(對單一 episode 的接觸失敗不敏感);`L0_peak`:**最大值**(峰值本來就是極值統計);`task_success`:**比例** | 每個 DV 的聚合函數在此寫死,不得事後更換 |

**總量估算(不含 λ 掃描):**
`A0`(1) + `A1`(1) + `A2`(42) + `A3`(1) + `A4`(1) + `R0`(1) + `R1`(1) = **48 條件 × 30 seed × 20 episode = 28,800 episodes**。
與 `DIRECTION.md` §11.5 的「幾天到一週機器時間」量級相符。

### 2.6 λ 掃描與 Pareto front

**λ = 目標函數中溫柔項的權重。** `objective = task_term − λ · gentleness_penalty`。

- **λ 掃描的層級:** `λ ∈ {0, 0.25, 0.5, 1, 2, 4}`(6 點,log 間隔加 0)。
- **λ 掃描只在 `A0`、`A1`、`A3`、`A4` 上跑**(4 臂 × 6 λ × 30 seed × 20 episode = 14,400 episodes)。**不在 42 個劣化條件上跑全 λ** —— 成本不允許,且 §1 H2-F5 已預先登記了「交叉點對 λ 敏感」這個推翻條件的**縮減版檢定**:在 `f ∈ {0.25, 0.5, 2.0, 4.0}` 四個代表點上加跑 `λ ∈ {0.5, 1, 2}`,檢查 `f*` 的區間是否重疊。
- **保真度掃描使用的固定 `λ*` 的選取規則(在看主對比之前寫死):**
  > `λ*` = 在 **`A0`(constraint baseline)臂上**,使 `task_success(λ) ≥ 0.8 × task_success(λ=0)` 成立的**最大** λ。
  這條規則**只讀 baseline 臂的任務成功率**,不讀任何 predictive-vs-constraint 對比,也不讀 `L2_dev`。因此它不污染 H1–H3。若 `A0` 在 λ=0 的 `task_success` 本身低於 0.5,則規則失效,改用 §7.2 的退場路徑。

## 3. 依變數:精確定義與單位

所有依變數在**評估時**由模擬器 ground truth 計算,**兩組控制器都看不到**(`DIRECTION.md` §5 的兩層分離)。

### 3.1 L0 —— 機械層(審稿人熟悉的錨點,有外部標準)

| 符號 | 定義 | 單位 |
|---|---|---|
| `L0_peak` | episode 內機器人與 myoArm 之間**接觸力合力大小的最大值**,以 `arm_scene.probe_contact_force` 的接觸幀→世界幀轉換後的向量範數計 | N |
| `L0_impulse` | `∫‖F(t)‖ dt`,對整個接觸區間積分 | N·s |
| `L0_press_ratio` | `max_t ( p(t) / p_limit(region) )`,其中 `p = ‖F‖ / A_contact`,`A_contact` 由 MuJoCo 接觸點數 × 單點等效面積近似;`p_limit` 取 **ISO 10218-2:2025 Annex M** 對應身體區域的**準靜態 pain-onset 壓力限值** | 無因次 |
| `L0_force_ratio` | 同上但用力限值而非壓力限值 | 無因次 |

**必須在論文中明寫的三件事:**
1. Annex M 的限值是 **pain-onset,不是 injury-onset**(`notes/VERIFIED_FACTS.md` §5)。
2. 限值來源受試者為 **16–67 歲、排除既有病況**(Behrens et al. 2022, PMC8850785,一手 Methods 已讀)。**不得寫「對長者太寬鬆」** —— Lautenbacher 2017 meta 顯示疼痛閾值隨年齡**上升**。
3. **不做軟組織**(MJX 不支援 flex),`A_contact` 是剛體接觸的近似,壓力項是**下界品質的代理**。

### 3.2 L1 —— 突然性

| 符號 | 定義 | 單位 |
|---|---|---|
| `L1_jerk` | 接觸點處機器人末端加速度的時間導數大小,取接觸區間內的 RMS | m/s³ |
| `L1_vapp` | **接觸瞬間**(第一個 `ncon > 0` 的控制步)機器人末端沿接觸法線的速度分量 | m/s |
| `L1_rom_excess` | `Σ_j max(0, |q_j| − q_j^lim)` 對 myoArm 所有有限位關節求和,時間積分 | rad·s |
| `L1_tendon_strain` | `max over MTU, t of (l − l₀)/l₀`,以 `d.actuator_length` 對 `rest_len` 計 | 無因次 |

`L1_tendon_strain` 的存在是為了對照 BATON / Prendergast 2021 的 harm channel(`notes/GENTLENESS_CONCEPT.md` §7 B1);他們用 <2% 的門檻,我們**報連續值不設門檻**,理由是他們的門檻來自解析 OpenSim 肩模型而非 myoArm。

### 3.3 L2 —— 主結果:**相對個人無接觸基線的預測激活偏差**

> **⚠️ 這是 2026-09-04 第四輪文獻回合的修訂。L2 **不是**共收縮絕對量。理由見 `notes/GENTLENESS_CONCEPT.md` §6:共收縮符號不定(Hodges & Tucker 2011)、與疼痛報告無關(Karayannis 2013 r²=0.33 只對恐懼)、長者因肌力弱基線更高(Falk 2022)、完全脊損反射放大但無感覺(Andersen 2004)。

**定義:**

1. **個人無接觸基線** `a⁰_i`:對每一個種子 `s`(= 一個「個人」),在**完全相同的初始姿勢、完全相同的重力沉降時間、機器人保持 `R0`(no-op)** 的條件下,量測第 `i` 條肌肉的穩態激活,取沉降後 `[T_settle, T_settle + 1.0 s]` 窗的時間平均。
   - 基線**每個種子各算一次**,與該種子的所有實驗臂共用。
   - 基線量測**屬 §0.2 的校準類**,允許在凍結後、主實驗前執行。

2. **偏差** `d_i(t) = a_i(t) − a⁰_i`(有號,可正可負 —— 這正是 Hodges & Tucker 的要求)。

3. **主要純量**
   ```
   L2_dev = ∫ ‖ d(t) ‖₁ / N_musc  dt        單位:s(激活無因次 × 時間)
   ```
   對 `N_musc` = 進入分析的肌肉集合(§3.3.1)取平均,對整個 episode 積分。
   **取 L1 範數(絕對值)而非有號和**,因為 Hodges & Tucker 的結論是「活動可增可減可重分配」,單一符號的讀法不成立。

4. **分解(必報,不可只報總量)**
   - `L2_dev_up = ∫ Σ max(d_i, 0) / N dt`(上調成分)
   - `L2_dev_dn = ∫ Σ max(−d_i, 0) / N dt`(下調成分)
   - `L2_cci_ratio`:`reflex.py::cci` 的 `ratio` 欄位,**只作為與既有文獻對照的次要量,不作為主結果**(它是絕對共收縮,正是被打掉的讀法)。

**⚠️ `reflex.py::cci` 的 docstring 在數學上自相矛盾(§9.4),使用前必須修正。且該檔目前沒有任何 baseline-relative 的函數 —— L2 的實作尚不存在。**

#### 3.3.1 肌肉集合

主分析用 `arm_scene.py` 已定義的四組:
`ELBOW_FLEXORS`(BIClong, BICshort, BRA, BRD)、`ELBOW_EXTENSORS`(TRIlong, TRIlat, TRImed, ANC)、`SHOULDER_ABD`(DELT1-3, SUPSP)、`SHOULDER_ADD`(PECM1-3, LAT1-3, TMAJ)。
**共 23 條。** 全 63 MTU 的版本作為預先登記的穩健性分析並列報(§4.7)。

#### 3.3.2 適用範圍(必寫進論文)

L2 只適用於**神經完整或輕度受損**的被照護者。完全脊損 / 急性脊髓休克 / 鎮靜狀態下,反射反應讀出的是**神經狀態**而非接觸傷害性(Andersen et al. 2004),proxy 雙向失效,必須重新校準或替換。定版英文措辭見 `notes/GAP_CLAIM.md` §4 第二段。

### 3.4 合成的 harm oracle

```
H = w0 · L0_press_ratio + w1 · L1_rom_excess_norm + w2 · L1_tendon_strain_norm + w3 · L2_dev_norm
```

- 每一項先用**其在 `R1`(random-action)臂上的第 95 百分位**做正規化,使四項可加。此正規化常數屬校準類(§0.2),在主實驗前一次算定並凍結。
- **`w` 的值待 Phase 0 決定**,且**必須做敏感度分析**:主結果在 `w` 的至少 3 種設定(等權、L2 主導、L0 主導)下各報一次。若結論的方向對 `w` 敏感,論文只能報**分項**,不報 `H`。
- **`H` 不是主要依變數。** 主要依變數是 `L2_dev`。`H` 存在是為了回答「你們只是選了一個對自己有利的指標」,而不是為了取代分項。這對映 `PAPER_AUDIT_SOP.md` A8(單位/尺度跨組比較)。

## 4. 統計計畫

### 4.1 主要統計量

**配對種子 + paired t 的 95% CI**(不是 p 值)。沿用第一階段(`INHERITED.md`、`../wm_prior/recompute_all.py`)。

對每個對比 `X − Y`:
- 報 `mean(X−Y)`、`95% CI = mean ± t₀.₉₇₅,ₙ₋₁ · SE`;
- 報 `n`、`SD_diff`、Cohen's `d_z = mean(X−Y)/SD_diff`;
- **同時報 `X` 與 `Y` 各自的 between-seed SD**(不是只報差的 SD),讓讀者看得到效果相對於自然散布的大小。

### 4.2 穩健性

- **BCa bootstrap 95% CI**,10,000 次重抽,**重抽單位 = seed**(不是 episode),以正確傳遞 §2.3 的相關結構;
- **Wilcoxon signed-rank**(配對);
- 三者若不一致,**三者全報**,並在論文中以「三種方法給出不同結論」陳述,不挑一個。

### 4.3 尺度敏感度(SOP A9)

每個主結果**至少兩種尺度各報一次**:
- `L2_dev`:原始尺度 + `log(1 + L2_dev)`;
- `L0_peak`:N + `log N`;
- `task_success`:比例 + logit(對 0/1 加 Haldane 修正)。
若某結果在一種尺度顯著、另一種不顯著,**明寫**。

### 4.4 窗口設計

**兩個窗口家族,主分析用 (a)。**

**(a) episode 內的接觸相位(主分析)** —— 這是「接觸前預測」這個宣稱真正活著的地方:

| 窗口 | 定義 | 子集關係 |
|---|---|---|
| `APPROACH` | episode 起點 → 第一個 `ncon > 0` 的前一步 | 與其餘互斥 |
| `ONSET` | 第一個 `ncon > 0` 起 **200 ms** | ⊂ `CONTACT` |
| `SUSTAINED` | `ONSET` 結束 → 最後一個 `ncon > 0` | ⊂ `CONTACT` |
| `CONTACT` | `ONSET ∪ SUSTAINED` | **是上兩者的聯集,不獨立計入**(SOP B4) |
| `RETRACT` | 最後一個 `ncon > 0` 之後 | 與其餘互斥 |
| `WHOLE` | 整個 episode | **是全部的聯集** |

**主要依變數 `L2_dev` 的主分析窗口 = `WHOLE`。** `ONSET` 是預先登記的**次要**窗口,因為 predictive 的機制主張(接觸前避開)預測 `ONSET` 上的優勢最大。**這個預測本身是預先登記的:若優勢在 `ONSET` 上不大於在 `SUSTAINED` 上,則機制解釋(前瞻)減弱,必須明寫。**

**(b) 他者模型訓練進程窗口(次要)** —— `EARLY / MID / LATE / ENDPOINT`,只適用於有線上適應的 variant。若本階段全用凍結模型,此家族**不執行**,並在論文中說明未執行。

**`window × condition` 交互作用檢定**沿用第一階段,對 (a) 執行。

**端點紀律(SOP B5):** `ENDPOINT` 一律寫「在固定預算的端點」,不寫「最終」或「收斂後」,除非另有收斂證據。

### 4.5 多重比較:**所有家族定義並列報,不後選**

> 家族由**規則**決定,不由結果決定(SOP B1/B2/B3)。以下六個家族在此**全部**寫死,論文中**全部並列報**,並額外報未校正值。校正方法:**Holm-Bonferroni**(對所有家族一致使用)。

| 家族 | 定義規則 | `k` |
|---|---|---|
| `F0` | 未校正 | — |
| `F1` | 只有 H1 的主要對比(`A1 − A0`,`L2_dev`,`WHOLE`) | 1 |
| `F2` | 三條假設的主要對比:`A1−A0`(H1)、`A2 的交叉點存在性`(H2)、`A3−A0`(H3) | 3 |
| `F3` | `F2` × 五個互斥/聯集窗口(`APPROACH, ONSET, SUSTAINED, RETRACT, WHOLE`) | 15 |
| `F4` | 保真度掃描的全部交叉檢定:7 軸 × 2 方向(`f<1`, `f>1`) | 14 |
| `F5` | `F2` × 主要與次要依變數全集(`L2_dev, L2_dev_up, L2_dev_dn, L0_peak, L0_impulse, L0_press_ratio, L1_jerk, L1_vapp, L1_rom_excess, L1_tendon_strain, task_success`) | 33 |
| `F6` | **全庫**:`F3 ∪ F4 ∪ F5` 去重後的全部對比 | 待列舉,**在主實驗開跑前由腳本機械列舉並凍結**(不得在看到結果後重數) |

### 4.6 交叉點 `f*` 的估計與不確定性

- 對每個軸與方向,`Δ(f)` 在 `log₂ f` 上做**單調保序回歸(isotonic regression)**,取穿越 0 的位置為 `f̂*`;
- `f*` 的 95% CI 由 **seed-level BCa bootstrap** 給出(重抽 seed,重跑保序回歸,取 `f̂*` 分布的百分位);
- 若某次 bootstrap 重抽中曲線不穿越 0,該次記為**右設限**;設限比例 > 20% 時,`f*` **只報下界**,不報點估計。**這條規則預先寫死,防止「用不穿越的重抽偷偷變窄 CI」。**

### 4.7 預先登記的穩健性分析(全部並列報,不擇優)

1. 肌肉集合:23 條主集合 vs 全 63 MTU;
2. seed 層級聚合:中位數 vs 平均;
3. `harm oracle` 權重 `w` 的 3 種設定;
4. 兩種尺度(§4.3);
5. `variant-2`(constraint 也讀他者模型設裕度,§2.2)。

### 4.8 預期效果量

**不編造。** 本文件**不預先宣告任何預期效果量的數值**,因為:
- 第一階段的 `+23.8 [+1.7, +45.8]` 是不同身體、不同任務、不同依變數,不可移植;
- L2 是本階段新造的指標,沒有先驗尺度。

**取而代之,預先登記的是「效果量必須跟什麼比」:** 見 §5.N4 的干擾旋鈕散布,以及 §6 表格的第三欄。**任何主結果都必須與 `A0` 臂 seed-only 的散布並列報。**

功效分析在 Phase 0 校準之後以 Amendment 回填(§6.1-C6)。若回填顯示 n=30 不足以偵測 §6 校準出的最小有意義效果,**增加種子數而不是放寬判準**。

> 全部在**主實驗之前**執行。任一項失敗 → 主實驗不得開跑,或該項對應的結果不得進入主分析。

| # | 檢查 | 通過判準 | 失敗的意義 |

| **N5** | **negative control:不接觸時指標應為零** | 機器人執行一條**保證不接觸**的軌跡:`L0_peak = 0`(嚴格)、`L0_impulse = 0`、`L1_rom_excess = 0`、`L2_dev < ε₂`(`ε₂` 待 Phase 0 定,為基線量測本身的重測散布的 2 倍) | 任一項非零 → 指標有洩漏(常見原因:重力沉降未收斂、基線窗選錯)。**這是最便宜、最容易被跳過、也最會抓到 bug 的一項** |

|---|---|---|---|

## 7. 停止規則與推翻條件

### 7.1 Gate A(接觸拓樸)—— 已定義,見 `verify_contact.py`

**不過 → 主實驗不得開跑。** 修幾何,重跑。已有一次假 PASS 紀錄(§5.C8)。

### 7.2 Gate B(共收縮對碰法是否敏感)—— `DIRECTION.md` §11.3 / §8 的推翻條件

**原文只寫「敏感 → 繼續;不敏感 → L2 失效,退回力 / 衝量」,沒有數值門檻。本文件補上:**

| 結果 | 判準 | 行動 |
|---|---|---|
| **通過** | `L2_dev` 在「快 / 深」與「慢 / 淺」接觸之間的差,paired CI 不含 0,**且**效果 ≥ `κ_B`(§6.1-C1) | 依本文件執行主實驗 |
| **邊際** | CI 不含 0 但效果 < `κ_B` | **不繼續。** 先調整接觸參數(深度、速度、接觸部位)使效果進入可用範圍,重跑 Gate B,並以 Amendment 記錄調了什麼。**調整次數上限 3 次**,超過即視為失敗 |
| **失敗** | CI 含 0 | **L2 失效。** 執行 §7.4 的退場路徑 |

`SpasticMyoElbow`(Yu et al. 2024)已示範反射模型能重現拉伸速度依賴的阻力,這是「會過」的先驗 —— 但**必須自己量,不得引用他人結果代替**。

### 7.3 掃描域擴展規則(防止事後擴域)

若 H2-F1 觸發(交叉點不在 `[0.25, 4.0]` 內):
- 允許**一次**對稱擴域至 `[0.0625, 16.0]`(log₂ 各再延兩格);
- 擴域**必須對七個軸同時執行**,不得只擴「看起來快穿越」的那一軸;
- 擴域結果以 Amendment 記錄,且論文中**必須報告原始域的結果**;
- 擴域後仍不穿越 → 報「在 `[1/16, 16]` 的雙向失配範圍內未觀察到交叉點」,**這是一個結果,不是失敗**,且它本身就是一條規格(「這個模型可以錯得很離譜」)。

### 7.4 退場路徑:L2 失效時

Gate B 失敗 → **不是專案結束**,而是降級為以下設計,且必須在論文中明寫降級發生:

1. 主結果改為 **L0 + L1**(力 / 衝量 / ROM 超限 / 肌腱應變);
2. `notes/GAP_CLAIM.md` §2 的 contribution ① 必須重寫 —— 溫柔不再定義在「預測激活偏差」上,退回機械傷害項;
3. **contribution ③(交叉點曲線)不受影響**,它是 centerpiece,且 `notes/GENTLENESS_CONCEPT.md` §7 B10 確認保真度當自變數是「零命中」;
4. 但必須誠實承認:退到 L0/L1 之後,`notes/GAP_CLAIM.md` §3 的 Zhao 2020 教訓重新生效 —— 若指標偏向「不碰就贏」,交叉點可能觀察不到。此時 **`task_success` 必須升為共同主要依變數**。

### 7.5 什麼結果會讓**整個方向**轉向

| 結果 | 為什麼致命 | 轉向到哪 |
|---|---|---|
| **H3-F3**(`A3 − A1` 的 CI 含 0:隨機他者模型與好模型不可區分) | 他者模型的**資訊內容**不重要 → 「溫柔需要一個他者模型」這個核心命題失效。H1 的優勢(若有)只是 planner 的優勢 | 轉為「predictive planning vs reactive filtering 在接觸任務中的比較」,他者模型降為手段而非主張。**論文的標題與 contribution 全部要改** |

## 9. 寫作本文件時發現的既有材料矛盾與漏洞

> **本節只記錄,不修改其他檔案**(本任務範圍限於新增 `PREREGISTRATION.md`)。每一條都應在主實驗前處理。

### 9.1 H3 在既有材料中沒有推翻條件
`DIRECTION.md` §8 只為「他者模型該預測狀態還是接觸力」寫了推翻條件(「Phase 0 若發現共收縮對機器人動作不敏感,退回力/衝量」)。`GAP_CLAIM.md` §7 的風險清單也只列了 Gate B。**「錯的模型比沒有模型更危險」這條假設,在本文件之前沒有任何預先寫定的否證條件** —— 而它恰恰是最容易被「randprior 只是沒幫助」這個較弱結果含糊帶過的一條。已於 §1 H3-F1..F4 補上。

### 9.2 主實驗場景尚不存在,而 Phase 0 的 probe 不能直接升級
`arm_scene.py` 的機器人是**單自由度 slide joint**。在 1-DoF 動作空間裡,CBF safety filter 只能做「進 / 退」,退化成閾值煞車 —— 這正是 `DIRECTION.md` §1 與 `GAP_CLAIM.md` §6 明文禁止的 strawman baseline。`DIRECTION.md` §11.4 已預警「雙身體場景是全新 setup,要花幾天」,但**沒有任何文件把「動作空間維度」寫成 baseline 有效性的前提條件**。已於 §2.1 與 §7.5 寫成硬約束。

### 9.3 L2 的實作不存在,且 `reflex.py` 現有的 `cci()` 正是被文獻打掉的那個讀法
`GENTLENESS_CONCEPT.md` §6 與 `DIRECTION.md` §11.1 已把 L2 改為「相對個人無接觸基線的預測激活偏差」,但 `scripts/reflex.py` 目前**只有 `cci()`(絕對共收縮指數),沒有任何 baseline-relative 的函數**。程式碼落後於概念定版一輪。

### 9.4 `reflex.py::cci()` 的 docstring 在數學上自相矛盾
docstring 同時給了三個不同的公式,並寫 `CCI = 2·min(A,B)/(A+B) · (A+B) = 2·min`,然後又說「scaled by (A+B)」得到 `2·min(A,B)`。實際回傳的 `ratio = 2·min(A,B)/(A+B)` 與 `magnitude = 2·min(A,B)` 是兩個不同的量,docstring 沒有把哪個是 Falconer-Winter 講清楚。**在論文引用這個指標之前必須改寫 docstring**,否則會成為 `PAPER_AUDIT_SOP.md` C5(強度錯)/ A1(數字與來源不符)的來源。

### 9.5 `DIRECTION.md` §5 的三層指標表是舊版
§5 的表格(L2 = 「對方的防禦性共收縮 / 肌肉激活變化」)是 2026-08-23 版,與同一份文件 §11.1 的 2026-09-04 定版(相對基線偏差 + 機械項合成)**互相矛盾**。§5 開頭雖有 ⚠️ 修訂註記,但表格本體未更新。任何從 §5 表格直接抄進論文的人會抄到被推翻的版本。

### 9.6 `README.md` 的「一句話核心命題」引用的是已被推翻的論證
`README.md` 寫「約束式的溫柔…**動作會顛簸**——而顛簸本身就會嚇到人」。`DIRECTION.md` §1 明確標示:**「原本寫的『約束式會顛簸』論證站不住」**,因為現代 CBF 是預測性地維持不變集。README 是新人第一份讀的文件,目前它教的是被自己專案推翻的論證。

### 9.7 `INHERITED.md` 違反專案自己的措辭紀律
`INHERITED.md` 第 53 行寫「**沒人測過**」。`DIRECTION.md` §2 明文:「據我們所知未見受控檢驗…**不可寫『沒人測過』**」。同一句話在 `DIRECTION.md` 是合規措辭,在 `INHERITED.md` 是違規措辭。屬 SOP D4(修一處漏五處)。

### 9.8 「七軸 × 七 factor」的條件數在文件與程式碼之間不一致
字面上是 49,`degrade.py::sweep_spec` 實際產生 **43**(`f = 1.0` 在全 spec 中只計一次)。論文若寫 49 即為 A1 類缺陷。

### 9.9 `degrade.py::_verify()` 是一個部分失明的驗證器
它證明「參數被改了」與「真模型未被污染」,但**沒有證明「被改的參數會改變行為」**;且對 `reflex_delay` 它檢查的是 `delay_s` 而不是實際生效的 `delay_steps`(有 `max(1, ·)` 的硬下界)。目前 `dt = 0.002 s` 下七個 factor 給出 `{3,6,9,13,18,25,50}` 步、未咬到下界,所以**現在沒有咬到**,但驗證器本身看不見這件事 —— 這是 `PAPER_AUDIT_SOP.md` §7「驗證器自己會瞎」的教科書實例。已於 §5.C3 / §5.C5 寫成必修項。

### 9.10 2×2×2 不是完全交叉
`DIRECTION.md` §4 的 2×2×2 在字面上有兩個未定義的 cell(見 §2.2)。若照字面跑,會產生三個數值完全相同的 cell 並被誤讀為「重複驗證」。已於 §2.2 改為明示的巢狀設計 + 預先登記的 variant-2。

### 9.11 `verify_contact.py` 的 500 N 與 ISO 限值無關
`SANE_FORCE_N = 500` 只防求解器爆炸。Annex M 的 pain-onset 限值遠低於此。Gate A 通過**不蘊含** L0 指標有可用的值域。已於 §5.C9 / §6.1-C2 補成獨立檢查。

### 9.12 未關閉的文獻覆蓋(額度耗盡,不是查過清白)
`GENTLENESS_CONCEPT.md` §5 與 `GAP_CLAIM.md` §7:**G4**(護理概念分析)、**G5**(複合傷害 oracle 先例)、**G6**(no-op 退化解)零存活 claim;2024–2026 arXiv world-model 預印本取樣不足;Chen et al. ASME 2024 全文未讀(付費牆)。**G5 對本文件特別重要** —— §3.4 的合成 harm oracle 正是 G5 的主題,而它的先例覆蓋是空的。論文的 related work **必須明寫這個覆蓋範圍**,不得暗示已窮盡。
